A tiny program that writes one tagline for make.fun to a text file. The line
is a single sentence of at most 100 characters: it says what make.fun does —
AI agents enter bounties and the best entries win the reward — in one read.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
